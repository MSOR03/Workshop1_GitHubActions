# Mi Proyecto - CI/CD Pipeline Workshop
![CI Pipeline](https://github.com/msor03/Workshop1_GitHubActions/actions/workflows/ci.yml/badge.svg)

Este proyecto es parte del taller práctico de Ingeniería de Software II sobre construcción de pipelines CI/CD.

## Descripción

Aplicación web simple construida con Express.js que demuestra la implementación de un pipeline CI/CD completo usando GitHub Actions.

## Endpoints

- `GET /` - Retorna mensaje de bienvenida
- `GET /health` - Retorna el estado de salud del servicio
- `GET /version` - Retorna la versión de la aplicación

## Instalación

```bash
npm install
```

## Ejecutar la aplicación

```bash
npm start
```

## Ejecutar las pruebas

```bash
npm test
```

## Pipeline CI/CD

El proyecto incluye:
- ✅ Integración continua con pruebas automatizadas
- ✅ Análisis de cobertura de código
- ✅ Despliegue automático a GitHub Pages
